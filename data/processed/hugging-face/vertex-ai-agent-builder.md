# Vertex AI

Vertex AI is Google Cloud's fully-managed, unified development platform for building, Huấn luyện (Training), deploying, and managing machine learning (ML) models at scale. It provides tools for the entire ML lifecycle, from data preparation and custom Huấn luyện (Training) with AutoML to model monitoring and deployment. Vertex AI offers access to Google's foundation models, such as Gemini, along with custom Huấn luyện (Training) options and tools for building Các tác nhân AI (AI Agents). It streamlines the ML workflow into a single interface, supporting both low-code and custom development on managed infrastructure
