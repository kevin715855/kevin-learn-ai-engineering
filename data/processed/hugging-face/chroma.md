# Chroma

Chroma is an open-source Cơ sở dữ liệu Vector and AI-native Biểu diễn nhúng (Embedding) database designed to handle and store large-scale Biểu diễn nhúng (Embeddings) and semantic vectors. It is used in applications that require fast, efficient similarity searches, such as natural language processing (NLP), machine learning (ML), and AI systems dealing with text, images, and other high-dimensional data.
