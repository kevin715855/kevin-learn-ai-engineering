# APIs tương thích với OpenAI

APIs tương thích với OpenAI là các giao diện mô phỏng cấu trúc và chức năng của API của OpenAI. Các API này cho phép nhà phát triển chuyển đổi giữa các mô hình ngôn ngữ hoặc các nhà cung cấp khác nhau chỉ với thay đổi mã nguồn tối thiểu. Điều này đặc biệt hữu ích để kiểm tra các mô hình khác nhau, giảm thiểu việc bị ràng buộc nhà cung cấp, hoặc xây dựng cơ chế dự phòng trong trường hợp xảy ra gián đoạn dịch vụ.
