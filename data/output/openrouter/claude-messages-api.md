# Claude Messages API

API Claude Messages cung cấp một cách có cấu trúc để tương tác với mô hình AI Claude. Nó cho phép các nhà phát triển gửi một chuỗi tin nhắn tới Claude, mô phỏng một cuộc trò chuyện. Những tin nhắn này có thể bao gồm văn bản, hình ảnh và thậm chí dữ liệu có cấu trúc, giúp bạn xây dựng các tương tác phức tạp và trích xuất những insight cụ thể từ phản hồi của mô hình qua các đầu vào và đầu ra có cấu trúc.
