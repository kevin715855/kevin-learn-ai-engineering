# API Vision OpenAI

OpenAI Vision API cho phép các mô hình phân tích và hiểu hình ảnh, cho phép chúng xác định các đối tượng, nhận diện văn bản và giải thích nội dung trực quan. Nó tích hợp xử lý hình ảnh với khả năng ngôn ngữ tự nhiên, cho phép thực hiện các tác vụ như visual question answering, image captioning và trích xuất thông tin từ ảnh. API này có thể được sử dụng cho các ứng dụng trong lĩnh vực tiếp cận nội dung, kiểm duyệt nội dung và tự động hoá, cung cấp một cách liền mạch để kết hợp sự hiểu biết về hình ảnh với các tương tác dựa trên văn bản.

Truy cập các nguồn tài nguyên sau để biết thêm chi tiết:
