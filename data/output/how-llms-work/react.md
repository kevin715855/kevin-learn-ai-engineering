# ReAct

ReAct (Reason and Act) prompting cho phép các mô hình ngôn ngữ lớn (LLM) giải quyết các nhiệm vụ phức tạp bằng cách kết hợp suy luận với tương tác với công cụ bên ngoài. Nó tuân theo vòng lặp suy nghĩ‑hành động quan sát: phân tích vấn đề, thực hiện các hành động sử dụng API bên ngoài, xem xét kết quả và lặp lại cho đến khi giải quyết. Hữu ích cho nghiên cứu, các vấn đề đa bước và các nhiệm vụ yêu cầu dữ liệu hiện tại.
