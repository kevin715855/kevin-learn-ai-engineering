# LangFuse

LangFuse là một nền tảng quan sát LLM mã nguồn mở cung cấp khả năng truy vết, quản lý prompt và công cụ đánh giá. Bạn có thể tự-host nó hoặc sử dụng phiên bản đám mây. Nó tích hợp với hầu hết các khung công trình và SDK phổ biến qua một API đơn giản, và cho phép bạn chấm điểm các truy vết theo cách thủ công hoặc tự động để xây dựng tín hiệu chất lượng theo thời gian.
