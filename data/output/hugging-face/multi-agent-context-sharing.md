# Chia sẻ bối cảnh đa đại lý

Chia sẻ ngữ cảnh multi-agent mô tả cách các agent AI riêng biệt làm việc trên các nhiệm vụ liên quan trao đổi thông tin mà mỗi agent cần. Khi một agent chuyển giao một nhiệm vụ cho agent khác, agent đó phải truyền đủ lịch sử và dữ liệu để agent thứ hai có thể tiếp tục mà không lặp lại công việc hoặc bỏ qua chi tiết quan trọng. Việc chia sẻ thiết kế kém có thể khiến các agent làm việc dựa trên hình ảnh nhiệm vụ lỗi thời hoặc không đầy đủ, trong khi truyền quá nhiều ngữ cảnh có thể lãng phí token và làm chậm hệ thống. Các cách tiếp cận phổ biến bao gồm các kho bộ nhớ chia sẻ, truyền thông điệp có cấu trúc giữa các agent, và một agent điều phối lọc thông tin mà mỗi sub-agent nhận được.
