# Google Gemini API

Google Gemini API cung cấp cho nhà phát triển quyền truy cập lập trình tới họ các mô hình AI đa phương thức của Google Gemini. Nó cho phép các ứng dụng hiểu và tạo ra nội dung qua văn bản, hình ảnh, âm thanh và video. Nhà phát triển có thể sử dụng API này để xây dựng các tính năng như giao diện trò chuyện, công cụ tạo nội dung và các hệ thống có thể phân tích và phản hồi với dữ liệu đa giác quan phức tạp.
