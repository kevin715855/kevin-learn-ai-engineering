# SDK suy luận

Hugging Face Inference SDK là một công cụ mạnh mẽ cho phép các nhà phát triển dễ dàng tích hợp và thực hiện suy luận trên các mô hình ngôn ngữ lớn được lưu trữ trên Hugging Face Hub. Bằng cách sử dụng `InferenceClient`, người dùng có thể thực hiện các cuộc gọi API đến các mô hình khác nhau để thực hiện các nhiệm vụ như tạo văn bản, tạo hình ảnh, và hơn thế nữa. SDK hỗ trợ cả các thao tác đồng bộ và bất đồng bộ, do đó tương thích với các quy trình hiện có.

Truy cập các nguồn tài nguyên sau đây để tìm hiểu thêm.

- [@article@Endpoint Setup](https://www.npmjs.com/package/@huggingface/inference)
