# Tools & Function Calling in Các tác nhân AI (AI Agents)

Tools and function calling equip Các tác nhân AI (AI Agents) with the ability to interact with the real world and access external information. Instead of just providing text-based responses, the agent can use predefined functions, tools, or APIs to perform specific actions like searching the web, sending emails, or controlling devices. This extends the agent's capabilities and allows it to solve more complex tasks that require actions beyond simple language generation.
