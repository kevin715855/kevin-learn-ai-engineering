# OpenAI AgentKit

OpenAI AgentKit is a framework designed to simplify the process of creating Các tác nhân AI (AI Agents) that can perform specific tasks by leveraging Các Mô hình Ngôn ngữ Lớn (LLMs) (LLMs). It provides tools and abstractions for managing agent state, defining agent behavior, and connecting agents to various tools and resources, allowing developers to build more complex and capable AI systems without needing to manage all the low-level details.
