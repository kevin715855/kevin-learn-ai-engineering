# Cơ sở dữ liệu Vector

When implementing Tăng cường Thế hệ bằng Truy xuất (RAG) (RAG), a Cơ sở dữ liệu Vector is used to store and efficiently retrieve Biểu diễn nhúng (Embeddings), which are vector representations of data like documents, images, or other knowledge sources. During the RAG process, when a query is made, the system converts it into an Biểu diễn nhúng (Embedding) and searches the Cơ sở dữ liệu Vector for the most relevant, similar Biểu diễn nhúng (Embeddings) (e.g., related documents or snippets). These retrieved pieces of information are then fed to a generative model, which uses them to produce a more accurate, context-aware response.
