# Indexing Biểu diễn nhúng (Embeddings)

Biểu diễn nhúng (Embeddings) are stored in a Cơ sở dữ liệu Vector by first converting data, such as text, images, or audio, into high-dimensional vectors using machine learning models. These vectors, also called Biểu diễn nhúng (Embeddings), capture the semantic relationships and patterns within the data. Once generated, each Biểu diễn nhúng (Embedding) is indexed in the Cơ sở dữ liệu Vector along with its associated metadata, such as the original data (e.g., text or image) or an identifier. The Cơ sở dữ liệu Vector then organizes these Biểu diễn nhúng (Embeddings) to support efficient similarity searches, typically using techniques like approximate nearest neighbor (ANN) search.
