# Claude Agent SDK

The Claude Agent SDK provides tools and libraries to build autonomous Các tác nhân AI (AI Agents) powered by Anthropic's Claude models. It simplifies the development process by offering pre-built components and abstractions for tasks such as planning, tool usage, memory management, and human interaction. This allows developers to focus on defining the agent's behavior and capabilities rather than the underlying infrastructure.
