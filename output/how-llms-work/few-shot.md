# Few-Shot Prompting

Few-Shot prompting is a technique used with Các Mô hình Ngôn ngữ Lớn (LLMs) (LLMs) where you provide a small number of example input-output pairs in the prompt itself. These Ví dụ demonstrate the desired behavior of the LLM for a specific task. By seeing these "few shots" of correct answers, the LLM can better understand the pattern and generate accurate and relevant responses for new, unseen inputs.
