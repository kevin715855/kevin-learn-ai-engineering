# Weaviate

Weaviate is an open-source Cơ sở dữ liệu Vector that allows users to store, search, and manage high-dimensional vectors, often used for tasks like Tìm kiếm ngữ nghĩa and recommendation systems. It enables efficient similarity searches by converting data (like text, images, or audio) into Biểu diễn nhúng (Embeddings) and indexing them for fast retrieval. Weaviate also supports integrating external data sources and schemas, making it easy to combine structured and unstructured data.
