# Whisper API

Whisper API của OpenAI cho phép các nhà phát triển tích hợp khả năng chuyển đổi giọng nói thành văn bản vào ứng dụng của họ. API sử dụng mô hình Whisper của OpenAI — một hệ thống nhận dạng giọng nói mạnh mẽ — để chuyển đổi ngôn ngữ nói thành văn bản chính xác, dễ đọc. API hỗ trợ nhiều ngôn ngữ và có thể xử lý nhiều tonal trình khác nhau, khiến nó trở nên lý tưởng cho các tác vụ như ghi âm, lệnh thoại và phụ đề tự động. Với khả năng xử lý âm thanh theo thời gian thực hoặc từ các file đã ghi trước, Whisper API giúp việc thêm tính năng nhận dạng giọng nói mạnh mẽ vào ứng dụng trở nên đơn giản hơn, nâng cao tính tiếp cận và cho phép trải nghiệm tương tác mới.
