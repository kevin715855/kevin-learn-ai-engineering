# Building an Máy chủ MCP

An MCP (Giao thức Ngữ cảnh Mô hình (MCP)) server acts as an intermediary between Các tác nhân AI (AI Agents) and various data sources or tools. It provides a standardized way for agents to access and interact with external information, enabling them to perform tasks that require context beyond their internal knowledge. Building an Máy chủ MCP involves defining the API endpoints, handling requests from agents, retrieving data from relevant sources, and formatting the responses in a way that the agents can understand.
