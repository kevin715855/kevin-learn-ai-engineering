# Context Compaction

Context compaction is a technique used to reduce the length of the context provided to a Mô hình Ngôn ngữ Lớn (LLM) (LLM) without sacrificing relevant information. This process aims to remove redundant, irrelevant, or less important information from the Cửa sổ ngữ cảnh to make room for more data or improve the efficiency and effectiveness of the LLM's processing. Compaction can involve techniques like summarization, filtering, or re-ranking of context information.
