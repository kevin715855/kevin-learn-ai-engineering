# API Phản hồi OpenAI

OpenAI Response API cho phép các nhà phát triển tương tác với các mô hình AI được cung cấp bởi OpenAI. Nó cung cấp một cách có cấu trúc để gửi yêu cầu đến các mô hình này và nhận được văn bản, mã hoặc các đầu ra khác được tạo ra. Bạn có thể kiểm soát các khía cạnh như prompt, temperature, độ dài tối đa và các tham số khác để điều chỉnh phản hồi sao cho phù hợp với nhu cầu cụ thể của bạn. API này được thiết kế để thay thế dần dần Assistants API và Chat Completions API cho các dự án mới.
