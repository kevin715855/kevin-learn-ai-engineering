# Context vs Prompt Eng.

Kỹ thuật Tạo câu lệnh (Prompt Engineering) focuses on how a single instruction is worded to get a better response from a model. Context engineering is broader: it deals with what information reaches the model at all, from which sources, in what order, and in what format, across an entire application or agent workflow. A well written prompt can still fail if the model lacks the right data, tools, or history to act on it. Context engineering treats the prompt as just one part of a larger system that also includes retrieval, memory, and tool outputs.
