# API Embeddings của OpenAI

API Embeddings của OpenAI cung cấp một cách đơn giản để chuyển đổi văn bản thành các biểu diễn vector số được gọi là embeddings. Những embeddings này nắm bắt ý nghĩa ngữ nghĩa của văn bản, cho phép bạn thực hiện các tác vụ như tìm kiếm ngữ nghĩa, phân cụm và so sánh độ tương đồng bằng cách phân tích mối quan hệ giữa các vector này. API đơn giản hoá quá trình tạo các embeddings này, loại trừ sự phức tạp của việc huấn luyện và quản lý các mô hình embeddings.

Hãy truy cập các nguồn lực sau để biết thêm chi tiết:
